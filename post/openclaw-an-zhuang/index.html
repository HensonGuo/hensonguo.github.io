openclaw安装

2026-03-12 3 min read

1. 安装git

2. 安装nodejs

  • 网址：https://nodejs.org/en/download
  • 上方版本可能会变，确保用最新的（LTS）即可

3. 启动powershell

  • 点击Win键 或 点击菜单开始键
  • 搜索Powershell 并用管理员身份运行

4. 安全策略设置

  • 输入：Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser 然后回车
  • 出现这个后输入大写的 Y 然后回车

5. 安装openclaw

  • 输入：iwr -useb https://openclaw.ai/install.ps1 | iex 然后回车

6. 安装好后回答

I understand this is personal-by-default and shared/multi-user user requires lock-down. continue?

选择Yes

9. 启动控制台

  • 查看网关状态
openclaw gateway status
  • 如果网关存在问题，退出360等，重启网关
openclaw gateway start
  • 如果还存在问题，通过doctor修复或重装网关
openclaw gateway uninstall
openclaw doctor --fix
openclaw gateway install
openclaw gateway start
  • 打开控制台
openclaw dashboard

打开网页时会提醒

unauthorized: gateway token missing (open the dashboard URL and paste the to

这是因为用户没有使用带终端令牌的链接打开，导致权限认证失败，在终端中运行

openclaw dashboard --no-open

10.重新配置openclaw

openclaw configure

11.安装skill

  • 安装clawhub的cli工具
npm i -g clawhub

-去clawhub搜索拷贝名称安装

clawhub install "baidu web search"
npx skills add https://github.com/JimLiu/baoyu-skills/tree/main/skills/baoyu-post-to-wechat

12.卸载小龙虾

openclaw uninstall --all --yes
  • --all 参数会删除包括网关服务、本地数据库、配置文件在内的所有数据。
  • --yes 参数让整个过程自动确认，无需手动干预。

删除命令行工具：等待上一条命令执行完毕后，再执行以下命令，彻底移除OpenClaw的命令行工具：

npm uninstall -g openclaw

13.问题

如果启动gateway失败，尝试

openclaw gateway --force

关闭360等软件再次安装重试
